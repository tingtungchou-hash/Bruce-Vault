# 词汇 lessico

## 动词 verbi
- restituire 归还、返还（restituire un libro 归还一本书）
- comprare 购买（comprare un vestito 买一件衣服）

## 房屋与家具 la casa e i mobili
- la parete 墙（多指室内墙面；il muro 指墙、外墙、承重墙）
- la scrivania 书桌、写字台
- il tavolino 小桌子、茶几
- il divano 沙发（较大，可供多人坐）
- la poltrona 扶手椅（单人）
- il comodino 床头柜
- il bidet 坐浴盆
- il gabinetto 马桶；卫生间（原笔记作 gebinetto）
- il lavandino 洗手池（原笔记作 lavadino）
- il bagno 浴室、卫生间

## 家居用品 oggetti per la casa
- l'abito / il vestito 衣服；西装；连衣裙
- le tende 窗帘（单数 la tenda）
- la maschera 面具
- la coperta 毯子
- le lenzuola 床单（单数 il lenzuolo；复数作阴性；原笔记作 lezuola）

## 方位与介词 preposizioni di luogo
- accanto a 在……旁边
- davanti a 在……前面
- dietro (a) 在……后面
- dentro (a) 在……里面
- sotto (a) 在……下面
- sopra (a) 在……上面
- vicino a 在……附近
- di fronte a 在……对面、正对
- intorno a 在……周围
- fuori da 在……外面
- lontano da 离……远
- a destra di 在……右边
- a sinistra di 在……左边
- tra / fra 在……之间

# 语法 grammatica

## 介词与冠词的缩合 preposizioni articolate
- a + il = al；a + lo = allo；a + la = alla；a + l' = all'；a + i = ai；a + gli = agli；a + le = alle
- di + il = del；di + lo = dello；di + la = della；di + l' = dell'；di + i = dei；di + gli = degli；di + le = delle
- da + il = dal；da + lo = dallo；da + la = dalla；da + l' = dall'；da + i = dai；da + gli = dagli；da + le = dalle
- in + il = nel；in + lo = nello；in + la = nella；in + l' = nell'；in + i = nei；in + gli = negli；in + le = nelle
- su + il = sul；su + lo = sullo；su + la = sulla；su + l' = sull'；su + i = sui；su + gli = sugli；su + le = sulle
- con 通常用 con + 冠词（con il, con la），缩合形式 col 较少用；per、tra / fra 不与冠词缩合。

## 方位介词的选择
- 表示“在……旁边、附近、对面、周围”时用 a：accanto a、vicino a、di fronte a、intorno a。
- 表示“在……外面、离……远”时用 da：fuori da、lontano da。
- 表示“在……左边 / 右边”时用 di：a sinistra di、a destra di；单独使用时可说 a sinistra / a destra。
- accanto、vicino、lontano 也可单独作副词；接名词时分别用 accanto a、vicino a、lontano da。
- davanti、dietro、dentro、sopra、sotto 可单独作副词；接名词时，davanti 通常用 davanti a，其余可直接接名词或加 a：dietro la porta / dietro alla porta；sotto il tavolo / sotto al tavolo。
- tra 与 fra 意思相同，可以互换；后接名词时不缩合：tra il tavolo e la sedia。

## 存在句 c'è / ci sono
- 本课句子见“课文”部分。C'è 后接单数名词，ci sono 后接复数名词；原句紧挨 C'è 的第一个名词是单数 un gabinetto，所以用 C'è。若强调两个物品，也可以说 Ci sono un gabinetto e un bidet。
- 缩合：di fronte a + il lavandino → di fronte al lavandino；in + il bagno → nel bagno。

## 名词的性与数
- la parete → le pareti
- la tenda → le tende
- la coperta → le coperte
- il lenzuolo → le lenzuola（单数阳性，复数阴性，不规则）
- il comodino → i comodini
- il divano → i divani
- la poltrona → le poltrone
- il gabinetto → i gabinetti
- il bidet → i bidet（外来词，复数不变）
- la scrivania → le scrivanie
- il tavolino → i tavolini
- l'abito → gli abiti
- il vestito → i vestiti

## 易混词 parole da distinguere
- la parete / il muro：parete 多指室内墙面，muro 指墙、外墙、城墙。
- il divano / la poltrona：divano 是多人沙发，poltrona 是单人扶手椅。
- il tavolo / il tavolino：tavolo 是桌子，tavolino 是小桌子、茶几。
- il bagno / il gabinetto：bagno 是浴室、卫生间（房间），gabinetto 是马桶、厕所。
- l'abito / il vestito：二者都可指衣服、西装、连衣裙；vestito 还可作“穿着的”形容词。
- accanto a / vicino a：accanto a 强调紧挨着，vicino a 只表示在附近。
- davanti a / di fronte a：davanti a 是“在……前面”，di fronte a 是“在……对面、正对”。

# 课文 testi

## 描述房间 descrivere la stanza
- C'è un gabinetto e un bidet di fronte al lavandino nel bagno. 浴室里，洗手池对面有一个马桶和一个坐浴盆。
- Il divano è grande ed è per molte persone. 沙发很大，可供多人坐。
- La poltrona è per una persona. 扶手椅是单人坐的。

## 句型练习 esercizi
- C'è un comodino accanto al divano. 沙发旁边有一个床头柜。
- La scrivania è vicino alla parete. 书桌靠近墙。
- Le tende sono davanti alla finestra. 窗帘在窗前。
- La maschera è sulla parete. 面具挂在墙上。
- La coperta è sul divano. 毯子在沙发上。
- La poltrona è a destra del divano. 扶手椅在沙发右边。
- Il tavolino è tra il divano e la poltrona. 小茶几在沙发和扶手椅之间。
