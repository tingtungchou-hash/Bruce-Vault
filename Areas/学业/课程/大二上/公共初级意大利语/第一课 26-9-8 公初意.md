# l'alfabeto italiano 
- 21 lettere, 5 vocali 15 consonanti 
- 5 lettere straniere 
	- J  => i lunga 
	- K => cappa 
	- W => doppia vu 
	- X => ics 
	- Y => ipsilon
## la pronuncia 
- A = a, artista 
- B = b, bandiera 
- **C** =
	- k before a, o, u, casa  
	- tsch before i, e, ciao, cinque 
- D = d, dado 
- E = e, esame 
- F = f, famiglia 
- **G** = 
	- g before a, o, u, gamba 
	- dj before i, e, gelato, già, bongiorno 
- H = no sound, hotel 
- I = i, italia 
- L = l, letto
- M = m, mano 
- N = n, naso 
- O = o, ombrello 
- P = p, pera 
- Q (u) = ku, quadro
- R = r, rana 
- S = 
	- s, scuola 
	- z, 
- T = t, topo 
- U = u, uovo 
- V = v, valigia 
- Z = 
	- z, zebra 
	- ts
- **CH** = k, chiesa 
- **GH** = g, spaghetti, ghiaccio
