IL TEMPO PASSATO PROSSIMO
- essere / avere (verbo ausiliare) + participio passato
- per i participi passati, 
	- are => ato 
	- ere => uto 
	- ire => ito 
	- ==助动词为essere时，需要ito/a配合，否则都用ito== 
	- i participi irregolari 
		- avere => avuto 
		- essere => stato (stare => stato)
		- andare => andato
		- fare => fatto 
		- prendere => preso
		- leggere => letto 
		- mettere => messo 
		- vedere => visto 
		- rimanere => rimasto 
		- venire => venuto 
quando uso essere e quando uso avere? 
- essere：表示移动、essere和stare的过去式、所有自反和相互动词
- avere：
![[Casa-di-ESSERE.webp]]
特殊用法动词（主语是“物/事”，常配 mi / ti / gli 等间接宾语）

| 动词 | 过去分词 | 释义与例句 |
|---|---|---|
| piacere | piaciuto | 使喜欢：mi è piaciuto |
| dispiacere | dispiaciuto | 使遗憾：mi è dispiaciuto |
| sembrare | sembrato | 似乎：mi è sembrato |
| bastare | bastato | 足够：mi è bastato |
| mancare | mancato | 缺少、想念：mi è mancato |
| succedere | successo | 发生：è successo |
| accadere | accaduto | 发生：è accaduto |

自反与相互动词 riflessivi / reciproci一律用 essere

注意
- 性数一致：essere + 过去分词，分词要与主语一致——sono andato / andata / andati / andate。
- “像移动却用 avere”的陷阱词：camminare（ho camminato）、viaggiare（ho viaggiato）、nuotare（ho nuotato）、ballare（ho ballato）；correre 两可（ho corso“跑过步” / sono corso a casa“跑到家”）。
- 两可（essere 与 avere 皆可，意义或地区有别）：vivere（ho vissuto 更常见）、crescere（sono cresciuto“长大” / ho cresciuto“抚养”）、costare（è costato / ha costato）、piovere 与 nevicare（ha piovuto / è piovuto）。
