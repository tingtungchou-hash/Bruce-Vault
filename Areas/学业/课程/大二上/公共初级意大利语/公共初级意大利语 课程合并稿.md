## 疑问词 parole interrogative

- perché 为什么：perché studi l'italiano? 你为什么学意大利语？

- che cosa 什么：che cosa fai stasera? 你今晚做什么？

什么时候用 lo

# 语法 grammatica

## 1. uscire 的变位（现在时 indicativo presente）
esco / esci / esce / usciamo / uscite / escono

## 2. piacere 的变位与用法
现在时：piaccio / piaci / piace / piacciamo / piacete / piacciono

informale（非正式）
- mi piace + 不定式 / 单数名词
- mi piacciono + 复数名词

formale（正式，Le ＝ 您）
- Le piace + 不定式 / 单数名词
- Le piacciono + 复数名词

间接宾语代词：mi = a me，ti = a te，gli = a lui，le = a lei（Le ＝ 您，正式）

## 3. 频率副词的位置
- 单个频率副词（sempre, spesso, quasi mai, raramente）跟动词走：简单时态在动词后（Io ascolto sempre musica）；复合时态放在助动词与过去分词之间（Ho sempre ascoltato…）
- non … mai：non 在动词前、mai 在动词后（正：Non fa mai yoga；误：Non fa yoga mai）——与法语 ne … pas 同理
- di solito / in genere / qualche volta / a volte / certe volte：常置句首或句末

## 4. il sabato 与 sabato
- il sabato（＝ ogni sabato，每周六）esco con mio peticolo amico.
- sabato（＝ questo sabato，这个周六）esco con mio peticolo amico.

## 介词 preposizioni: a / al / in / di
缩合形式
- a + il = al；a + lo = allo；a + la = alla；a + l' = all'；a + i = ai；a + gli = agli；a + le = alle
- in + il = nel；in + lo = nello；in + la = nella；in + l' = nell'；in + i = nei；in + gli = negli；in + le = nelle
- di + il = del；di + lo = dello；di + la = della；di + l' = dell'；di + i = dei；di + gli = degli；di + le = delle

用法
- a 城市、小岛、无冠词场所；时间点；间接对象；方式。a Roma, a Capri, a casa, a scuola, a teatro, a mezzogiorno, a piedi, A me piace il rock.
- al 是 a + 定冠词，用于名词前有冠词时。al cinema, al bar, al lavoro, al distributore, al primo piano, all'università, alla stazione, alle poste.
- in 国家、大区、大岛；封闭空间或机构。in Italia, in Toscana, in Sicilia, in banca, in biblioteca, in ufficio, in classe, in mensa, in segreteria, in ascensore, in bagno.
- in + 定冠词。nell'aula magna, nel centro storico.
- di 所属、来源、材料、内容、主题、时间、比较；di + 不定式。il libro di Marco, Di dove sei?, un pacchetto di fazzoletti, un corso di italiano, di mattina, più alto di me, cercare di capire.
- di + 定冠词。il libro del professore, i nomi degli studenti.
- 注意：动词不定式前不缩合，vado a mangiare、cerco di capire；城市用 a，国家/大区用 in；固定搭配要整块记。

## andare 与 venire
- andare：离开说话人所在处，朝第三方目的地移动
- andare insieme：双方从当前地点共同出发，地位对等，目的地是“别处”

- venire：朝说话人或听话人所在处移动，即向参照点靠拢
- venire con qualcuno：一方加入另一方
	- Vieni con noi? 你来加入我们吧？
	- Vengo con te. 我跟你一起去。
- 对比
	- Vai con lui? 你跟他去吗？（离开我这边）
	- Vieni con lui? 你跟他来吗？（朝我这边）
- 判断：中性的“我们一起去”用 andare insieme；邀请对方加入说话人一方用 venire con noi；自己加入对方用 venire con te

# 语法 grammatica

## 必要性表达 espressioni di necessità
- 结构：è necessario / bisogna + 动词不定式
- prenotare un albergo 预订旅馆
- avere il passaporto 有护照
- portare i vestiti 带衣服
- portare il cellulare 带手机

## 地点代词 ci
- ci vado spesso = vado spesso lì / là = vado spesso a... 我常去那里
- ci vado sempre 我总是去那里

## 部分冠词 articolo partitivo
- dei, degli, delle 一些（阳性复数与阴性复数）
- alcune / alcuni 一些（与部分冠词同义）
- un museo famoso → dei musei famosi 一座著名的博物馆 → 一些著名的博物馆
- una chiesa famosa → delle chiese famose 一座著名的教堂 → 一些著名的教堂

## 复数结尾音节的保持 plurali
- 阴性 -ca / -ga 结尾的词，复数一律作 -che / -ghe：tipica → tipiche
- 阳性 -co / -go 结尾的词分两种：
	- 重音在倒数第三音节（antepenultima）时作 -ci / -gi：tipico → tipici，medico → medici，amico → amici（amico 属例外）
	- 重音在倒数第二音节（penultima）时作 -chi / -ghi：tedesco（重音在 e）→ tedeschi，antico（重音在 i）→ antichi

## 副词与形容词 avverbio e aggettivo
- voglio mangiare molto 我想吃很多（molto 为副词，修饰 mangiare）
- a Pechino ci sono molti monumenti famosi 北京有许多著名的纪念建筑（molti 为形容词，修饰 monumenti）

## 情态动词 potere 与 sapere
- non sa leggere：（因为不识字）不会读书
- non può leggere：（现在因为没带眼镜、眼睛被蒙住了等）不能读书
- non sa parlare：（婴儿、哑巴等）不会说话
- non può parlare：（嘴巴被蒙住了等）不能说话
