# 补充说明
- volere 的条件式 vorrei 表示礼貌的“我想要”，第七、八课均见。
- piacere 的主语是被喜欢的事物：mi piace + 不定式或单数名词，mi piacciono + 复数名词；正式场合用 Le piace / Le piacciono。
- uscire 与 venire 的 noi、voi 形式保留不定式词干（usciamo、uscite；veniamo、venite），其余人称换用另一词干。
- c'è / ci sono（有）是 essere 的固定用法：单数用 c'è，复数用 ci sono（第六课）。
- 未列入本表的规则动词：parlare、abitare、lavorare（-are）；prendere（-ere，现在时规则）；preferire（-isc 型：preferisco、preferisci、preferisce、preferiamo、preferite、preferiscono）；offrire（-ire 规则）；mancare（-are，常用 manca / mancano）。
- 课文对话中还出现 potere（puoi）、sapere（sai、so）等不规则动词的个别形式，笔记未给出完整变位，故未收入本表。
