# Original Text
haec tu scis ad me esse delata; quae si velim proferre, facile omnes intellegent vobis inter vos non modo voluntatem fuisse coniunctam, sed ne praedam quidem adhuc esse divisam. quapropter si tibi indicium postulas dari quod tecum una fecerit, concedo, si id lege permittitur; sin autem de accusatione dicimus, concedas oportet iis qui nullo suo peccato impediuntur quo minus alterius peccata demonstrare possint.

# Text Analysis
haec tu scis ad me esse delata; quae si velim proferre, facile omnes intellegent vobis inter vos non modo voluntatem fuisse coniunctam, sed **ne** ==praedam== **quidem** adhuc esse divisam. quapropter si tibi ==indicium== postulas dari quod tecum una fecerit, concedo, si id lege permittitur; ==sin== autem de accusatione dicimus, concedas oportet iis qui nullo suo ==peccato== ==impediuntur== quo minus alterius peccata demonstrare possint.

# Translation
This you know is reported to me; which if I wish to leak forth, easily all know that not only had willingness been connected among you but also that the spoil is not even divided yet till this time. because of which, if you demand the information to be given to you which he did with you together, I concede, if it is allowed by law; if we talk about the accusation however, you concede that it is proper to them who are hampered by nothing mistaken of theirs, ~~in which way~~ ***due to which*** they are less able to demonstrate it is mistaken of another one.  

你知道，这些事情已经有人报到我这里来了。如果我愿意把它们抖出来，所有人都不难明白：你们彼此之间不仅意志一致，而且连赃物至今都还没有瓜分。因此，如果你要求把‘他与你共同做过的事’作为告发材料交给你，我同意——只要法律允许；但如果我们谈的是由谁提起控诉，那你就应当让给那些没有因自身罪过而受阻、因而能够揭露别人罪过的人。

# Vocabulary

- peccātum, -ī n.：罪过、过失、错误。动词 peccō, peccāre, peccāvī, peccātus 1.（犯错、犯罪）。文中两见：nullō suō peccātō 为中性单数夺格，作原因状语，“因自身任何罪过”；alterius peccāta 为中性复数宾格，作 dēmōnstrāre 的宾语，“他人的罪过”。单复数交替（peccātō / peccāta）构成同根词重复，强化“己过—人过”的对举。
- impediō, impedīre, impedīvī, impedītus 4.：阻碍、妨碍、阻止。文中 impediuntur 为第三人称复数现在时被动直陈式，“受阻碍、被妨碍”；与 quo minus ... possint 构成“受阻而不能……”的句式。常见搭配：impedīre aliquem quo minus / nē + 虚拟式；被动 impedīrī quo minus + 虚拟式。参见 [[impedīmentum, -ī n.]]（障碍物——同根名词）。

# Grammar

## 1. `concedas oportet iis qui nullo suo peccato impediuntur quo minus alterius peccata demonstrare possint`

（前句 sin autem de accusatione dicimus 为条件从句，与上文的 si tibi indicium postulas ... 相对；本句是主句，宾语 accusationem 承前省略。）

### 语法树

```
主句
├─ 谓语 oportet（无人称，3 sg. 现在时直陈）
└─ 从句（省略 ut）concedas
    ├─ 主语（隐含：你，指 Caecilius）
    ├─ 宾语（隐含：accusationem，承前省略）
    ├─ 与格宾语 iis
    │   └─ 关系从句 qui … possint
    │       ├─ 主语 qui
    │       ├─ 状语 nullo suo peccato（原因夺格）
    │       ├─ 谓语 impediuntur（被动）
    │       └─ 障碍从句 quo minus … possint
    │           ├─ 连词 quo minus
    │           ├─ 宾语 alterius peccata
    │           ├─ 补足语 demonstrare（不定式）
    │           └─ 谓语 possint（虚拟式）
```

### 细部用法

quo minus［连接词］：引出“阻止、妨碍”类动词后的障碍从句，相当于“使……不能、妨碍……”。impediō 的常见搭配为 impedīre aliquem quo minus / nē + 虚拟式；被动 impedīrī quo minus + 虚拟式。此处与 nullō ... peccātō 连用，形成多重否定：“不因任何罪过而受阻，以致不能……”，实即“完全有资格……”。

alterius［属格 单数］：alter, -era, -erum 的属格，修饰 peccāta，“另一个人的（罪过）”，此处暗指 Verres。与前面的 suō 形成“自己的／他人的”对照。

词序与修辞：nullō suō peccātō 置于 impediuntur 之前，alterius peccāta 置于句末，形成“自己的罪过—他人的罪过”的首尾对照；peccātō 与 peccāta 的单复数变化亦有强调作用。全句以 nullō、impediuntur、quo minus 三层否定叠加，反衬出“无瑕者可任控诉”之意。

> 译文：但如果我们谈的是控诉，你就应当把它让给那些没有因自身任何罪过而受阻、能够揭露他人罪过的人。
