# 核心课程设计思想

上级导航：[[李宇轩（f. 李丹）家教导航]]

## 一、构想

把整个家教课程做成一个世界观连贯的故事，而不是一课一篇互不相干的文章。每一课都是这个世界里的一段情节，学生跟着同一批人物往下走。

课程固定包含四个维度：

1. 阅读故事：本课的世界观章节
2. 完成题目：围绕章节设计的阅读题
3. 故事复盘：梳理情节、人物与结构
4. 课后练习：词块与题型的巩固

故事中承担两种额外功能：

- 人物介绍：借人物出场交代背景、时间线与经历，覆盖传记与应用文体裁
- 科学发现：借人物对话讲世界观的组成部分，把科普内容自然嵌入叙事

两个目的：

- 用故事性解决学习动机问题。他不肯学，说教无效，但会想知道“后来呢”
- 用故事的不同组成部分，覆盖阅读题的主要题型，而不是另找材料刷题

## 二、题型映射

| 故事元素 | 覆盖的题型 |
| --- | --- |
| 情节推进、人物行为 | 细节理解、事件排序 |
| 人物对话 | 词义猜测、指代、态度与语气推断 |
| 科学发现段落 | 说明文主旨、事实细节、因果关系、数字信息 |
| 人物介绍段落 | 传记与应用文体裁、时间线、成就与身份 |
| 悬念与转折 | 推断、预测、作者意图 |
| 故事复盘环节 | 主旨概括、篇章结构 |

这张表是这个构想最站得住的部分：中考与校内阅读的主要体裁就是记叙、说明、应用三类，连载故事天然覆盖记叙，人物对话天然承载说明，人物介绍天然承载应用。不是硬凑，是结构上的对应。

## 三、可行性评估

支持这个做法的四条理由：

1. 匹配学情。孩子的问题不是能力而是意愿，叙事是绕开抵触最省力的形式，初一男生尤其吃这一套。
2. 词汇复现天然发生。连载让人名、场景、核心词块反复出现，这正好治他词汇量缺口这个根因。孤立词表忘得快，故事里的词有语境。
3. 长期动机是稀缺品。“下周会发生什么”这种动机，刷题永远给不了。
4. 对老师本人也是资产。语料自产，不依赖教材，一学期下来就是一本可复用的书，也构成对家长的差异化卖点。

必须正视的风险，按严重程度排列：

1. 产量与质量是最大变量。每周产出新章节，同时控制词汇难度、复现率、题型配比，是写作与教学设计的双重负荷。以目前的备课节奏看，可持续性是整个设想的成败关键，而不是故事好不好看。
2. 难度控制变难。世界观越丰富，专有名词与背景词越多，对本就词汇缺口大的学生是额外负担，容易把阅读课变成猜谜。
3. 故事性与应试性相互拉扯。题目太密破坏阅读体验，太疏则覆盖不足，“在不打断叙事的地方嵌入题目”说起来容易做起来难，前期必然要试错。
4. 题材押注风险。他的兴趣点目前完全未知，世界观若选错方向，前期投入可能作废。
5. 复用率没有想象中高。换一个学生，程度与兴趣都不同，世界观不能直接搬。
6. 家长的评估口径。她要的是分数，“有意思”很容易被听成“不务正业”，必须用数据把故事课程的成果翻译成她认的语言。

结论：方向成立，优势明显，但可行性不取决于构想，取决于生产流程能否稳住。若不解决产量问题，三周后就会供不上课。

## 四、落地建议

1. 先用第一课探题材。以《The Dog at the Bus Stop》试水，观察他对悬疑、动物、运动、科幻哪一类有反应，世界观按反应定，不要先定好再套。
2. 骨架要小。一个与他同龄的主角、一个固定场景、一个持续谜题，先跑起来。不要开局就搭宏大设定。
3. 滚动生产，永远留缓冲。开课前把前三到四课写完，之后每周补一课，始终保持三课余量。这一条是可行性的关键。
4. 结构模板化。四段固定结构（故事、题目、复盘、练习）加固定题型配比，把每课的决策成本压到最低。
5. 词汇分两册。世界观核心词进词块卡、纳入考核、必须复现；一次性装饰词只求理解，不考。避免专有名词失控。
6. 科普段落克制使用。每两到三课插一次，借人物对话引出，控制在 80 词内，配一组数据或一张图。它是说明文题型的载体，不是主线。
7. 定一个可量化的评估口径，每月给家长一份曲线。故事课程的成果必须能被换算成数字，否则撑不住她的追问。
