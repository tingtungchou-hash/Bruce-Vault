# quoniam (conj.)

## 基本信息
- **语言**: 拉丁语
- **词性**: conj. (从属连词)
- **词源**: *quom* (= *cum*, when/since) + *iam* (already); 字面义 "既然已经……"

## 释义

1. since now, since then, seeing that, because, whereas (引出理由/依据，区别于 *quod* 的直接因果)
   a. ★ + **直陈式** (陈述事实): *quoniam ad hunc locum perventum est* — 既然已经到了这一步 (Caes. B.G. 6.11; 本课用法)
   b. + **虚拟式** (转述他人理由或主观推测): *quoniam cīvitātī cōnsulere nōn possent* — 既然 (据他们说) 无法兼顾部落利益 (Caes. B.G. 5.3)

## 关联词汇
- [[quod (conj.)]] (因为——直接原因; 对比 *quoniam* = 既然、鉴于)
- [[quia (conj.)]] (因为——口语化直接原因)
- [[cum (conj.)]] (当……时 / 既然——多义词)

## 复习提示
- **不建议背闪卡**。作为连词, 知道意思即可, 不值得投入记忆时间
- 本课用法: ⑦ *quibus quoniam ... satisfēcerit* = "既然对这些事他已经尽到了……" (虚拟式，因是 Ambiorix 的主观说法在间接引语中)
- 区分: *quoniam* = "既然 / 鉴于" (让步性原因); *quod* = "因为" (直接原因); *quia* = "因为" (口语化)
