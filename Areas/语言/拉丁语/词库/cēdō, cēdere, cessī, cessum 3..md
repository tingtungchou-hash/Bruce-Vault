# cēdō, cēdere, cessī, cessum 3.

## 基本信息
- **语言**: 拉丁语
- **词性**: v. (第三变位，不及物；少数情况及物)
- **词源**: 可能为 `cado` 的重复形式（`*ce-cado`）

## 释义
1. 行进、走动（基本义，诗歌罕见）
   - `non prorsus, verum transvorsus cedit, quasi cancer` — 他不是直走，而是横着走，像螃蟹
2. 特定义项（核心高频用法）
   a. **离开、撤退、退出**（从某处离去）：
      - `cedo atque abibo` — 我会离开
      - `patria cedere` — 离开祖国
      - **军事术语**：`loco cedere` — 放弃阵地、撤退
      - `ex acie cedere` — 退出战线
      - **商业术语**：`foro cedere` — 退出市场 = 破产
   b. 生命/时间消逝：`vita cedere` — 去世；`horae cedunt` — 时间流逝
   c. **让步、屈服、退让**（接与格）：
      - `cedere alicui` — 向某人让步
      - `Pelides cedere nescius` — 不善退让的阿喀琉斯
      - `cedere fortunae` — 向命运低头
      - `cedere nocti` — 因天黑而撤退
   d. **不如、次于**（接与格，表比较）：
      - `neque multum cedebant virtute nostris` — 他们在勇猛上也不比我方差多少 (BG 2.6)
   e. （及物）**给予、让出、割让**：
      - `multa de iure suo cedere` — 放弃许多自身权利
      - `victoriam hosti cedere` — 把胜利让给敌人
3. 其他引申
   a. 归属于、落入：`captiva corpora Romanis cessere` — 俘虏归了罗马人
   b. 结果是、变成：`temeritas in gloriam cesserat` — 鲁莽反而变成了荣耀
   c. 有结果、进展：`bene/male cedere` — 进展顺利/不顺
