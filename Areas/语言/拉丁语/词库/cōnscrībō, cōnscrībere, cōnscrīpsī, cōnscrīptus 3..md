# cōnscrībō, cōnscrībere, cōnscrīpsī, cōnscrīptus 3.

## 基本信息
- **语言**: 拉丁语
- **词性**: v. trans. (第三变位法)
- **词源**: *con-* + *scribo* ("to write together")

## 释义
1. To write together in a roll or list, to enroll
   a. Milit. t.t.: to levy troops
      - *legiones conscribere* = to levy/enroll legions
      - *exercitum conscribere* = to raise an army
   b. Of colonists: to enroll for a colony
   c. *Patres Conscripti* = the enrolled/assembled Fathers (formal title of senators)
2. To put together in writing, to draw up, compose, write
   a. *librum conscribere* = to compose a book
   b. *epistulam conscribere* = to write a letter
   c. *testamentum conscribere* = to draw up a will
   d. *legem conscribere* = to draft a law
3. (meton.) To write something all over, to fill with writing (rare)
