# cōnstituō, cōnstituere, cōnstituī, cōnstitūtum 3.

## 基本信息
- **语言**: 拉丁语
- **词性**: v. (第三变位法)
- **词源**: *com-*（一起）+ *statuō*（立定）

## 释义

1. to cause to stand, put or lay down, to set, put, place, fix, station, deposit（安放、安置、驻定）
   a. milit. t. t. 布阵、驻扎：*legiōnem cōnstituere*；亦指使行军「停止」
2. with the idea of preparation, to set up, erect, establish, found, build, constitute（建立、创建、设立）
   a. *oppidum / moenia / castra cōnstituere*
   b. trop. 尤用于法律裁断：*iūdicium / quaestiōnem cōnstituere*（设立审判）
3. with the idea of ordering, to establish, fix, appoint, settle, order, regulate, arrange（规定、安排、整顿）
4. with the idea of limiting, to fix, appoint, settle, agree upon, define, determine（约定、议定、确定）
   a. *diem / pretium / modum cōnstituere*
   b. 商谈用语：*cōnstituere cum aliquō*（与某人约定）
5. with the idea of resolving, to resolve, decide, determine（决定）
   a. with inf. / acc. and inf. / interrog.-clause / *ut*
