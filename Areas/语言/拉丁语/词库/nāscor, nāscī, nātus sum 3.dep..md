# nāscor, nāscī, nātus sum 3. dep.

## 基本信息
- **语言**: 拉丁语
- **词性**: v. dep. (第三变位，异态动词)
- **词源**: 源自 *gnāscor* (古体); PIE 词根 *genh₁-; 对应希腊语 γίγνομαι, 英语 kin
- **注意**: 古体拼写为 *gnāscor, gnātus*

## 释义

1. to be born, spring forth, arise (经典通用义)
   a. *paterfamiliae illūstriōre locō nātus* — 出身于颇为显赫地位的家长 (见 Caes. *B.G.* 6.19 — **本课用法**; *nātus* = 完成分词)
   b. *nātus ex + abl.* — 生于（某母）
   c. *nātus + abl.* — 生于（某家族/阶层），如 *summō locō nātus*（出身最高阶层）

2. (引申) to arise, originate, spring forth
   a. *flūmen nāscitur in montibus* — 河发源于山中
   b. *ex hōc nascitur ut* — 由此得出……

3. 完成分词作名词: *nātus, -ī m.* = 儿子; *nāta, -ae f.* = 女儿; *nātī, -ōrum* = 子女

## 复习提示
- 完成分词 *nātus* 极常用：*locō nātus* = "出身于……阶层"
- 异态动词：形式被动但意义主动——*nātus sum* = "我出生了"（而非"我被出生"）
