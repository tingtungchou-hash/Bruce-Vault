# quoad (adv., conj.)

## 基本信息
- **语言**: 拉丁语
- **词性**: adv. / conj. (不变词)
- **词源**: *quod-ad* = "to which" > "as far as"

## 释义
1. (interrog.) How long? Until when? (rare)
2. As long as (with indicative)
3. Until, till that (with subjunctive — **important Caesar usage**)
   a. *quoad* + pluperf. subj. = "until such time as X should have happened"
4. As far as, so far as
   a. *quoad possum* = "as far as I can"
   b. *quoad ejus facere possum* = "as much as I am able"
5. With respect to, as to (= *quod attinet ad*)

## 复习提示
- 本课出现: `quoad ... cōgnōvisset` — "until he should have learned" (BG V.24.8)
- **关键区别**: *quoad* + indic. = "as long as" | *quoad* + subj. = "until"
- 你译成了 "as long as"，正确应为 "until"
