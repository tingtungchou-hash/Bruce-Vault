# dēficiō, dēficere, dēfēcī, dēfectus 3

## 基本信息
- **语言**: 拉丁语
- **词性**: v. 3 (dē- + faciō)
- **词源**: dē + faciō 

## 释义
1. to fail/falter 
2. to run short/out 
	1. cum eius generis cōpia dēfēcit [[Note - Day 1 Class 15#^dd6673|Caes.]]
3. to grow weak/faint 
4. to come to an end 
5. to revolt/rebel
