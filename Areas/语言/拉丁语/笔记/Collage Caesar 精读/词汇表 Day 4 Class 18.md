## 动词

1. ★ [[cōgō, cōgere, coēgī, coāctus 3.|cōgō]] — 强迫，迫使 (3, co- + agō; 本课: coāctus est = 他被迫)
2. ★ [[contineō, continēre, continuī, contentus 2.|contineō]] — 容纳，限制，克制 (2, con- + teneō; 本课: continēbantur = 被限制在)
3.  [[collocō, collocāre, collocāvī, collocātus 1.|collocō]] — 安置，驻扎 (1, con- + locō; 本课: collocāvit = 他驻扎)
4. ★ [[praeficiō, praeficere, praefēcī, praefectus 3.|praeficiō]] — 置于…之上统领 (3, prae- + faciō; + dat. 表示统领对象)
5. [[peragō, peragere, perēgī, perāctus 3.|peragō]] — 完成，结束 (3, per- + agō; 本课: perāctō conciliō = 会议结束后)
6. [[cōnscrībō, cōnscrībere, cōnscrīpsī, cōnscrīptus 3.|cōnscrībō]] — 征募，登记 (3, con- + scrībō; 本课: cōnscrīpserat = 他已征募)
7. ★ [[medeor, medērī 2.dep.|medeor]] — 治疗，补救 (2.dep., + dat.; 本课: inopiae medērī = 缓解粮荒)
8. ★ [[moror, morārī, morātus sum 1.dep.|moror]] — 逗留，耽搁 (1.dep.; 本课: morārī cōnstituit = 决定逗留)
9. [[dēdō, dēdere, dēdidī, dēditus 3.|dēdō]] — 投降，交出 (3, dē- + dō)
