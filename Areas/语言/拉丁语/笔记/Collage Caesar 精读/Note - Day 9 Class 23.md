## 补充说明

### 非人称被动 (*impersonal passive*)
拉丁语不及物动词（vi.）也可以构成被动形式，但无人称主语。此时动词永远用**第三人称单数中性**，翻译为 "人们/有人..." 或转为英语被动。本课出现多处：

| 形式                     | 原动词                          | 含义                            |
| ---------------------- | ---------------------------- | ----------------------------- |
| `resisteretur` (l. 27) | `resisto, -ere` (vi. + dat.) | "遭到抵抗"                        |
| `consurgitur` (l. 40)  | `consurgo, -ere` (vi.)       | "大家一同起身"                      |
| `pronuntiatur` (l. 49) | `pronuntio, -are` (vt.)      | 此处实为人称被动 ("被宣布")，主语是 `ituros` |
| `maneatur` (l. 56)     | `maneo, -ere` (vi.)          | "人们无法停留"                      |
| `augeatur` (l. 57)     | `augeo, -ere` (vt.)          | 人称为 `periculum` 作主语 = "危险被增大" |

> Caesar 在叙述军事行动时大量使用非人称被动，以营造客观、集体行动的语感。遇到单数被动 + 无明确主语的句子时，优先考虑是否为非人称用法。

### `quare` + 虚拟式
`quare` (= *qua re*, "因此/由此") 引导的从句使用**虚拟式**时，表达的不是纯粹的结果，而是带有**目的/意图色彩**的结果 —— 即某人为了达到某种效果而刻意安排某事。5.31.5 中：

```
Omnia excogitantur, quare nec sine periculo maneatur et... periculum augeatur.
```

`maneatur` 和 `augeatur` 均为现在虚拟式。字面义："所有安排都被想出来，**借以使得**既不能无危险地留下，又使危险加剧。"Caesar 在此暗示罗马人自作聪明地把自己逼入了两难处境。翻译时可处理为 "whereby" 或 "by which means" 而非单纯的 "so that"。
