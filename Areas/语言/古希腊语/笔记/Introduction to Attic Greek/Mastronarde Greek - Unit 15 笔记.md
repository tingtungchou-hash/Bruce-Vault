# Consonant Stems Ending in a Liquid or Nasal 

词干以流音（ρ、λ）或鼻音（ν）结尾。与 Unit 14 相同处不重复，只记特殊点：

- nom. sing. 与 voc. sing. 都没有格词尾，但 nom. sing. 用词干的强元音形式，即 ο 变 ω：ῥήτωρ、δαίμων
- 例外是 ἅλς，唯一的 λ 词干名词，nom. sing. 仍加 -ς
- acc. sing. 的词尾为 -ᾰ
- 词干以 ν 结尾者，dat. pl. 中 ν 不出现，但也没有补偿性延长（no compensatory lengthening）
- 历史附注：δαίμοσι 无 ν 也无补偿性延长，其解释是来自 dat. pl. 词尾 -ασι（即本节 §2 诸名词中所见），只是元音被其他格同化
- 重音：词干为 -ων 且重音落在词干末音节者（如 ἀγών），遵守 “accented long P followed by short U must have a circumflex” 的规则
- ἅλς 作为单音节词干的重音，见 Unit 14.2

# Irregular Stems in ρ

三个亲属称谓名词的词干以 ρ 结尾且有变体：πατήρ (father)、μήτηρ (mother)、θυγατήρ (daughter)。特殊点：

- 词干有三种形式
- 强元音形式 -τηρ，只出现在 nom. sing.
- 正常级 -τερ-，短元音，出现在若干格
- 弱级 -τρ-（gen. sing.、dat. sing.），或 -τρᾰ-（dat. pl.）
- 词干：πατ(ε)ρ-、μητ(ε)ρ-、θυγατ(ε)ρ-
- 常见名词 ἀνήρ (man) 类似，但阿提卡形式除 nom. sing. 与 voc. sing. 外，各格都在 ρ 前插入 δ，词干作 ἀνερ-／ἀνδρ-

重音的特别处：

- 四个词的 voc. sing. 都用 recessive accent：πάτερ、μῆτερ、θύγατερ、ἄνερ
- μήτηρ 与 θυγάτηρ 的 nom. sing. 也用 recessive accent
- πατήρ 与 μήτηρ 的三音节形式重音在第二音节（词干末 -ερ-，或 dat. pl. 的 -ρα-）：πατέρα、πατέρες、πατέρων、πατράσι(ν)
- 单音节词干的重音规则（Unit 14.2）正常适用于 πατήρ 与 μήτηρ 的 gen. sing. 和 dat. sing.，θυγάτηρ 依类推同样处理
- ἀνήρ：单音节词干诸形式同此规则；nom. sing. 与 dat. pl. 的双音节词干则重音在词干第二音节（voc. sing. 如上，用 recessive accent）

# Stems in Sigma

两类：阳性专名 -ης, -ους；中性名词 -ος, -ους。二者本为 -εσ- 词干，多数格中 σ 在元音间脱落，余下的 ε 与格词尾的元音缩合（contraction）；dat. pl. 中双 σ 变单 σ。特殊点：

- 阳性名词 nom. sing. 的 -ης 是 -εσ- 的强元音形式
- 纯词干见于阳性名词的 voc. sing.，且用 recessive accent：Σώκρατες
- -ης 名词的 acc. pl. 与 nom. pl. 同形（Σωκράτεις），不是通常的 -ᾰς
- 中性名词 nom.／acc.／voc. sing. 的 -ος 是 -εσ- 的 o-级变体
- 少数 σ 词干中性名词词干末为 -ασ-（如 γέρας），σ 一脱落同样发生缩合
- 词形表中括注的未缩合形式见于诗歌与其他方言
- 历史附注：-ης, -ους 类专名在古典时期已出现借自 a-变格的 acc. sing. 替代词尾 -ην，如 Σωκράτην 偶见，代替 Σωκράτη
- 词汇附注：ἡ τριήρης 是“三列桨”的复合形容词转作名词，古人认为其 gen. pl. 重音异常，作 τριήρων 而非预期的 τριηρῶν

# Interrogative Pronoun τίς, τί

- 疑问代词／疑问形容词，相当于英语的 who?、which?、what?
- 词干：多数格用鼻音词干 τιν-；masc./fem. nom. sing. 与 neut. nom. sing.、acc. sing. 用简单的 i-词干
- 有共同的 personal gender，一个形式兼作阳性与阴性（对比 Unit 9 的两尾形容词，以及 Unit 22 将学的同类）
- 中性照例只在 nom. 与 acc. 与阳性／阴性有别
- gen. sing.、dat. sing. 有替代形式（下表括注），属 o-变格，形同冠词的对应形式；实际句子里通常可认出是疑问词而不致歧义
- 重音：因疑问语调，acute 落在第一（或唯一）音节，且单音节疑问词后接他词、中间不停顿时，acute 也不变为 grave（对比 Unit 17 将学的 indefinite enclitic 形式）；gen. sing.、dat. sing. 的替代形式用 circumflex

词形：

| 数   | 格         | 阳性／阴性       | 中性          |
| --- | --------- | ----------- | ----------- |
| 单数  | nom.      | τίς         | τί          |
| 单数  | gen.      | τίνος (τοῦ) | τίνος (τοῦ) |
| 单数  | dat.      | τίνι (τῷ)   | τίνι (τῷ)   |
| 单数  | acc.      | τίνα        | τί          |
| 双数  | nom. acc. | τίνε        | τίνε        |
| 双数  | gen. dat. | τίνοιν      | τίνοιν      |
| 复数  | nom.      | τίνες       | τίνα        |
| 复数  | gen.      | τίνων       | τίνων       |
| 复数  | dat.      | τίσι(ν)     | τίσι(ν)     |
| 复数  | acc.      | τίνας       | τίνα        |

双数三性同形，阳性／阴性与中性无别；括注为 o-变格的替代形式。
