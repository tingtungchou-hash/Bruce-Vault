# Imperfect Verbs
## Augment 
### contraction 
- syllabic augment ἐ- 
- augment when verb starts with a vowel 

|     | ἐ-  |
| --- | --- |
| ᾰ   | η   |
| ε   | η   |
| ῐ   | ῑ   |
| ο   | ω   |
| ῠ   | ῡ   |
| αι  | ῃ   |
| ει  | ῃ   |
| αυ  | ηυ  |
| ευ  | ηυ  |
| οι  | ῳ   |

- ==ἔχ- => ἐἔχ- => εἴχ-== 
- ἀγ- => ἠγ- 
- αἱρε- => ᾑρε-
- ὠφελε- => ὠφελε- 
### component verbs  
- elision instead of contraction takes place. 
## Morphology 

### gramma 

|        | active | mid/pass | active | mid/pass |
| ------ | ------ | -------- | ------ | -------- |
| sing 1 | -ν     | -μην     | -ον    | -ομην    |
| sing 2 | -ς     | -σο      | -ες    | -ου      |
| sing 3 | —      | -το      | -ε(ν)  | -ετο     |
| sing 1 | -μεν   | -μεθα    | -ομεν  | -ομεθα   |
| sing 2 | -τε    | -σθε     | -ετε   | -εσθε    |
| sing 3 | -ν     | -ντο     | -ον    | -οντο    |
### example: πέμπω 

|        | active    | mid/pass   |
| ------ | --------- | ---------- |
| sing 1 | ἔπεμπον   | ἐπεμπόμην  |
| sing 2 | ἔπεμπες   | ἐπέμπου    |
| sing 3 | ἔπεμπε(ν) | ἐπέμπετο   |
| sing 1 | ἐπέμπομεν | ἐπενπόμεθα |
| sing 2 | ἐπέμπετε  | ἐπέμπεσθε  |
| sing 3 | ἔπεμπον   | ἐπέμποντο  |
### contract verbs in -έω 
- οἰκέω => ἐ + οἰκέω => ᾠκέ- ον/ες/ε/ομεν/ετε/ον/ομην/ου/ετο/ομεθα/εσθε/οντο
- => ᾤκουν, ᾤκεις, ᾤκει, etc.  
## Accentuation 
- the accent is recessive, but ==it cannot precede the first preverb element==. 
## Sepcial Verbs 
### ==εἰμί==
| pers | sing   | pl         |
| ---- | ------ | ---------- |
| 1    | ἦν / ἦ | ἦμεν       |
| 2    | ἦσθα   | ἦτε / ἦστε |
| 3    | ἦν     | ἦσαν       |
### ==χρή==
- χρῆν (ἐ +χρή)
- ἐχρῆν (χρή + imperfect of εἰμί)
### οἴομαι
- special 1 sing ᾤμην instead of ᾠόμην
# Meaning 
- action in the past that was incomplete, usually as a background, continuous or repeated (as opposed to aorist)
- corresponds to the English past progressive, verb phrases with *used to*, and in some contexts simple past
