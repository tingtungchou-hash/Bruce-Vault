# 第四课

1. mauvais **adj** 坏的，差的 *malus, mala, malum*
2. chaud(e) **adj** 热的 *calidus, calida, calidum*
3. froid(e) **adj** 冷的 *frigidus, frigida, frigidum*
4. doux, douce **adj** 柔软的；温和的 *dulcis, dulce*
5. sec, sèche **adj** 干的，干燥的 *siccus, sicca, siccum*
6. le nuage **nm** 云 *nubes, nubis*
7. mouillé(e) **adj** 湿的 *mollis, molle*
8. le bain **nm** 洗澡，沐浴 *balneum, balnei*
9. le nez **nm** 鼻子 *nasus, nasi*
10. le renard **nm** 狐狸
11. le bureau **nm** 办公室；书桌 *burra, burrae*（粗布，引申为书桌、办公室）
12. le pompier **nm** 消防员
13. le lait **nm** 牛奶 *lac, lactis*
14. la fleur **nf** 花 *flos, floris*
15. le père **nm** 父亲 *pater, patris*
16. regarder **v** 看，注视
17. aîné(e) **n & adj** 年长的；长子/女 < VL *antianatus* < *ante* + *natus, nati*
18. oublier **v** 忘记 *obliviscor, oblivisci* 
19. le nom **nm** 名字；名词 *nomen, nominis*
20. actuel(le) **adj** 当前的，现实的 *actualis, actuale* < *actus, actus*
21. la grippe **nf** 流感
22. assez **adv** 足够地；相当 *ad* + *satis*
23. le singe **nm** 猴子 *simius, simii*
24. le poulet **nm** 鸡；鸡肉 *pullus, pulli*
25. loin **adv** 远 
26. vouloir **v** 想要 *volo, velle*
27. lécher **v** 舔
28. patron(ne) **n** 老板 *patronus, patroni* < *pater, patris*
29. lâcher **v** 松开，放开 *laxare* < *laxus, laxa, laxum*
30. plusieurs **adj indéf pl** 好几个，多个*pluriores* < *plus, pluris*
31. le mois **nm** 月份 *mensis, mensis*
32. le décalage **nm** 差距；时差
33. casser **v** 打破，打碎 *quassare*
34. l'œuf **nm** 蛋，鸡蛋 *ovum, ovi*
35. creuser **v** 挖，掘 *cavus, cava, cavum*（空心 > 挖空）
36. la tête **nf** 头 *testa, testae*（陶罐 > 头）
37. plaire **v** 使喜欢，讨人喜欢 *placeo, placere*
38. l'arrêt **nm** 停止；车站 *ad* + *restare*
39. fumer **v** 抽烟；冒烟 *fumare* < *fumus, fumi*
40. le feu **nm** 火 *focus, foci*（炉膛 > 火）
41. court(e) **adj** 短的 *curtus, curta, curtum*
42. devoir **v** 应该；欠 
43. gêner **v** 妨碍，使不舒服
44. lorsque **conj** 当……的时候 < *illa hora*（那时）
45. le bagage **nm** 行李
46. tout **adv** 完全地，很 *totus, tota, totum*
47. voyager **v** 旅行 *viaticum, viatici* < *via, viae*
48. les vacances **nf pl** 假期 *vacantia* < *vacare*
49. la chambre **nf** 房间，卧室 *camera, camerae*
50. le dessin **nm** 图画，素描 < it. *disegno* < *designum, designi*
51. le stylo **nm** 钢笔 *stilus, stili*
52. la chose **nf** 事情，东西 *causa, causae*（原因 > 事物）
53. la veille **nf** 前夕，前一天 *vigilia, vigiliae*
54. voisin(ne) **n** 邻居 *vicinus, vicini* < *vicus, vici*
55. le nid **nm** 巢，窝 *nidus, nidi*
56. vivre **v** 生活；居住 *vivere*
57. jamais **adv** 从不；曾经 
58. rester **v** 留下，停留 *restare* < *re* + *stare*
59. soit **conj** 即，也就是说 *sit*（虚拟式"就是"）
60. haïr **v** 仇恨，憎恨
61. le frère **nm** 兄弟 *frater, fratris*
62. demander **v** 问；要求 *demandare* < *de* + *mandare*
63. la bourse **nf** 钱包；奖学金；交易所 *bursa, bursae*
64. la faim **nf** 饥饿 *fames, famis*
65. pousser **v** 推；生长 *pulsare* < *pellere*
66. voler **v** 飞；偷 *volare*
67. la jambe **nf** 腿 *gamba, gambae*
68. plus **adv** 更，更多 *plus, pluris*
69. enfant **n** 孩子，儿童 *infans, infantis*（不会说话的）
70. la nourriture **nf** 食物 < VL *nutritura* < *nutrire*
71. premier(-ère) **adj** 第一的；初级的 *primarius, primaria, primarium* < *primus, prima, primum*
72. vrai(e) **adj** 真的，真实的 *verus, vera, verum*
73. l'homme **nm** 人；男人 *homo, hominis*
74. hardi(e) **adj** 勇敢的，大胆的
75. le drapeau **nm** 旗帜
76. la lune **nf** 月亮 *luna, lunae*
77. l'ouvrage **nm** 工作；作品 *opera, operae*
78. remporter **v** 带走；赢得，获得 *reportare* < *re* + *portare*
79. abonné(e) **adj & n** 订阅的；订户
80. la trou **nf** 洞，孔
81. le mur **nm** 墙 *murus, muri*
82. le sang **nm** 血 *sanguis, sanguinis*
83. l'oie **nf** 鹅 *avis, avis*
84. le chou **nm** 卷心菜，白菜 *caulis, caulis*
85. le vélo **nm** 自行车 *velox, velocis* + *pes, pedis*（快 + 脚）
86. le bateau **nm** 船
87. la randonnée **nf** 远足，徒步旅行
