# 第一课

1. le lit **nm** 床 *lectus, lectus*
2. la salle **nf** 房间，厅室
3. le fils **nm** 儿子 *filius, filii*
4. le château **nm** 城堡 *castellum, castelli < castrum, castri*
5. le cheveu **nm** 头发 *capillus, capilli*
6. l'avocat **um** (l'avocate **nf**) 律师
7. l'ami **nm** (l'amie **nf**) 朋友 *amicus, amici*
8. malade **adj** 生病的
9. le/la malade **n** 病人
10. l'ouvrier **nm** (l'ouvrière **nf**) 工人 *operarius, operarii < operor, perari< opus, opus*
11. la grue **nf** 鹤，起重机
12. l'abeille **nf** 蜜蜂 *apicula, apiculae < apis, apis*
13. la crevette **nf** 虾
14. le pas **nm** 脚步
15. le sigle **nm** 缩写

17. la femme **nf** 女人
18. là **adv** 那边
19. ici **adv** 这里
20. bas(e) **adj** 低的 *bassus, bassa, bassum*
21. le bas **nm** 长筒袜
22. souvent **adv** 经常
23. tard **adv** 晚地 *tarde*
24. haut(e) **adj** 高的
25. fort(e) **adj** 强壮的，擅长的 **adv** 很，非常，有力地
26. le mille **nm** (mille **adj**) 一千
27. l'âme **nf** 灵魂 *anima, animae*
28. l'âne **nm** 驴子，蠢货 *asinus, asini*
29. avoir **v** 有 *habeo, habere, habui, habitum*
30. mal **adv** 不好地
31. la patte **nf** 爪子
32. le pied **nm** 脚 *pes, pedis*
33. le SIDA **nm** 艾滋病（Syndrome d'Immunodéficience Acquise）
34. le diable **nm** 鬼魂（口语，见鬼了） *diabolus, diabuli*
35. la piscine **nf** 泳池 *piscina, piscinae*
36. la bague **nf** 戒指 *baca, bacae*
37. la balle **nf** 子弹
38. la nappe **nf** 桌布，台布 *mappa, mappae*
39. la botte **nf** 靴子

41. le maïs **nm** 玉米
42. l'île **nf** 岛屿 *isula (lat. vulg.) < insula, insulae*
43. le Pâques **nm** 复活节
44. la cible **nf** 目标
45. le solde **nm** 降价出售的商品 *solidus, solidi*
46. l'avis **nm** 见解 *visum, visi < video, videre, vidi, visum*
47. facile **adj** 容易的 *facilis, facile*
48. le tas **nm** 堆 *êtat (fr.) < sto, stare, stedi, statum*
49. le sable **nm** 沙子
