## 代词
法语中需要提前的代词有：直接宾语人称代词、间接宾语人称代词、副代词
### 代词提前（I）
#### 语法部分
##### 直接宾语人称代词
直接宾语要求确指（le, la, les, ce, cet, cette, mon, ton, son, ma, ta, sa等等），否则用副代词en（见后文）

|     | 第一人称 | 第二人称 | 第三人称  |
| --- | ---- | ---- | ----- |
| 单数  | me   | te   | le/la |
| 复数  | nous | vous | les   |
Je regarde cet oiseau. => Je le regarde.
Par la fenêtre, je vois une femme. => Par la fenêtre, je la vois.

注意：
2. me, te, le, la在元音字母或哑音h前要省音
3. 否定句中，ne ... pas要夹住代词和动词（**适用于所有需要提前的动词**）

### 代词提前（II）
#### 语法部分
##### 间接宾语人称代词
间宾人称代词代替à引出的及物动词的简介宾语

|     | 第一人称 | 第二人称 | 第三人称 |
| --- | ---- | ---- | ---- |
| 单数  | me   | te   | lui  |
| 复数  | nous | vous | leur |
Le distributeur livre la commande à son client. => Le distributeur **lui** livre la commande.

### 代词提前（III）
#### 语法部分
##### 副代词y
1. 代替à后面的句子成分
	1. Tu veux assister **à ce concert**? 
	2. Oui, je veux **y** assister. 
	3. **注意：ne … pas否定要将y与动词一并包括在内**
	4. Le nouveau stagiaire participe **à la réunion**? 
	5. Non, il n'**y** participe pas. 
	6. **注意：间接宾语的à不符合这一条，用间接宾语人称代词**
	7. Il passe une banane à sa secrétaire. 
	8. ~~Il y passe une banane.~~ Il lui passe une banane. 
2. 代替由介词引出的地点状语
	1. Tu vas **chez ton neveu**? 
	2. Oui, j'**y** vais.
	3. Les hirondelles font leur nid **sous le toit**. 
	4. Oui, elles **y** font leur nid.  
##### 副代词en
1. 代替de后的句子成分（不管de的具体意思）
	1. À quelle heure la grenouille est-elle sortie **du pupitre**? 
	2. Elle **en** est sortie à midi. Du coup, le prof était fou de rage tout l'après-midi.
	3. **注意：ne … pas否定要将en与动词一并包括在内**
	4. Le cuisinier a-t-il parlé **de sa recette**? 
	5. Non, il n'**en** a pas parlé. 
2. 代替直接宾语（前面是不定冠词或部分代词）
	1. Vous allez manger **des huîtres**? 
	2. Oui, je vais **en** manger. 
	3. Vous allez manger **ces huîtres**?
	4. Oui, je vais **les** manger. 
	5. Le mari de mon ancienne petite-amie a-t-il **des cheveux**? 
	6. Non, il n'**en** a pas, Il est chauve. 
3. 代替数字后面的名词
	1. **Combien de chauve-souris** y a-t-il dans le chaudronde la sorcière ?
	2. Il y **en** a six. 
	3. **Combien de reins** as-tu? 
	4. J'avais dex reins, mais le chirurgien m'**en** a amputée un il y a une semaine. 

### 代词式动词
#### 语法部分
##### 代词式动词
自反代词（se）+ 动词 = 代词式动词
se要根据不同人称作相应变化，动词正常变位即可

|     | 第一人称 | 第二人称 | 第三人称 |
| --- | ---- | ---- | ---- |
| 单数  | me   | te   | se   |
| 复数  | nous | vous | se   |

代词式动词的用法
1. 自反
	1. laver 洗 => se laver 洗自己，洗澡
	2. appeler 叫 => s'appeler 叫自己，名字叫…
	3. promener 遛 => se promener 遛自己，散步
	4. coucher 放倒 => se coucher 放倒自己，睡觉
	5. lever 升起来 => se lever 把自己升起来，起床
2. 相互
	1. rencontrer 遇见 => se rencontrer 相遇
	2. aimer 爱 => s'aimer 相爱/爱自己
	3. 注意：
		1. 因为表示相互，主语为复数
		2. 在很多情况下，一个动词可以同时表示自反和相互
		3. Nous nous regardons. 表示“我们看自己/照镜子”或“我们面面相觑“
3. 被动
	1. dire 说 => se dire 被说
		1. Lent se dit "man" en chinois. 
	2. vendre 卖 => se vendre 被卖
		1. Ce livre se vend très bien. 
	3. 注意：
		1. 自反动词表示被动仅为少数情况，大多数情况表示被动是用被动语态
		2. ~~Il s'aime de tout le monde.~~
		3. Il est aimé de tout le monde.
4. 绝对（自反动词和动词原意相去甚远）
	1. s'en aller 离开
		1. Je sortirai avec un gars grand, beau et riche. Un jour, sa mère me donnera rendez-vous dans un café et jettera **sa carte** bancaire sur la table en disant, "Je vous offre dix millions de yuans **pourvu que** vous quittiez mon fils tout de suite." Je dirai, "Merci **ma tante**." et je m'en irai avec la carte... Voilà mon vœu pour cette nouvelle année. 
	2. se rendre compte (que) 意识到
		1. Ce vieux couple crédule a dépensé **la moitié** de ses économies pour acheter de soi-disant "produits de soins de **santé**" qui, **d'après** le fournisseur, pouvaient **soulager**, et même guérir la toux. Un an plus tard, le mari est mort du cancer **du poumon**. Regardant les faux médicaments qui s'entassent jusqu'**au plafond** chez elle, la vieille dame s'est rendu compte qu'ils étaient tombés dans **un piège**. 
	3. se souvenir de 想起
		1. M. Duan lui-même se mit à douter, "C'est vrai que je suis sorti avec trop de femmes, en ferait-elle partie? Mais pourquoi ne **me souviens-je de rien**?"
