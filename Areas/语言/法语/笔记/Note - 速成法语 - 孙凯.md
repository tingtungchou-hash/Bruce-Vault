# 语音部分
## 预备性知识
### 音符
长音符、开音符、闭音符、分音符、软音符（让应发k的c发s，例如ça va中的ça）
### 音节
1. 音节以元音为基础，每个元音*音素*（而非元音字母，例如table，仅有以a为中心构成的一个音节，ble不算一个音节）构成一个音节
2. 元音间的两个辅音（不一定是字母，例如exercice，音节划分应为ek-ser-cice三个音节）分属前后两个音节
3. 以元音结尾的音节为开音节，以辅音字母结尾为闭音节
### 基本拼读规则
1. 每个字母如非根据规则不发音，都要发音（例如psychologie，应为psy-cho-lo-gie，而非sy-cho-lo-gie），除了：
	1. 字母h
	2. 在词尾的e
	3. 在词尾的辅音字母（c, f, l, r除外，例如lit读作li，但sur仍要读作sur）
2. 两个相同字母连在一起时，只发一个音（例如Anne），cc在e, i, y前除外，例如succ**e**ssion
3. 规则重叠时，字母组合优于字母，分音符优于字母组合

#### 语法部分
##### 主语人称代词

|     | 第一人称    | 第二人称      | 第三人称         |
| --- | ------- | --------- | ------------ |
| 单数  | 我 je    | 你 tu      | 他/她 il/elle  |
| 复数  | 我们 nous | 你们/您 vous | 他们 ils/elles |
注意：il/elle可以表示非人类的"它"，依据名词的性选择相应代词
例如：J'ai **une** banane. **Elle** est délicieuse. 我有根香蕉，它很好吃。
J'ai **un** raisin. **Il** est délicieux. 我有颗葡萄，它很好吃。
##### 名词的性和数
1. 名词分为阴性和阳性，通常是约定俗成的，没有规律可循
2. 名词分为单数和复数
	1. 变成复数一般加s，s结尾的词的复数为原形（如fils复数仍然是fils，fils的读音属于例外，读作fils）
	2. 部分以al结尾的词变复数把al变位aux（如animal变为animaux）
	3. 部分以eau结尾的词变复再词尾加eux（如château变位châteaux）
3. 表示人的职业、身份、国籍以及部分表示动物的名词，变成阴性加e，变成复数加s（如avocat变为avocate，avocats，avocates；éléphant变为éléphante，éléphants，éléphantes。注意不同性的拼写引起的读音改变）如果原词以e结尾，变为阴性时为原型
4. 有些动物的阴阳性是固定的，与自然性别无关（如rat，moustique为阳性，abeille，crevette为阴性）
##### 定冠词和不定冠词

|      | 阳性  | 阴性  | 复数  |
| ---- | --- | --- | --- |
| 不定冠词 | un  | une | des |
| 定冠词  | le  | la  | les |
例如：un lit，une salle，des lits，des salles；le lit，la salle，les lits，les salles

#### 语法部分
##### 基本句型：c'est与ce sont
1. C'est un colis. 这是个包裹。
2. C'est une chaise. 这是把椅子。
3. Ce sont des colis. 这是几个包裹。
4. ce sont des chaises. 这是几把椅子。
连颂（la liaison）：c'est une chaise > sedün chaise

##### 重读人称代词

|     | 第一人称 | 第二人称 | 第三人称      |
| --- | ---- | ---- | --------- |
| 单数  | moi  | toi  | lui/elle  |
| 复数  | nous | vous | eux/elles |
1. 用于省略句中
	1. -Qui? -Moi. 
	2. J'adore la bibiothèque, et **toi**? 
2. 用于c'est后面
	1. Madame Bovary, c'est **moi**. 
3. 用于介词后
	1. Julie désire voir un film avec **moi**. 
4. 用作主语的同位语，表示强调
	1. Les Chinois, eux, ils utilisent les baguettes a table

##### 否定句
否定变位动词，用ne...pas夹住动词
1. Ce **n'** est **pas** un oiseau. 
2. Il **ne** prend **pas** le récipient. 

##### 形容词
1. 一般放在名词前
2. 少数常用的单音节/双音节词可以放名词前，如
	1. grand, petit, beau, bon, long, mauvais, court, jeune, vieux, joli, large
3. 形容词要与它所修饰的名词保持性、数配合
	1. un ami intelligent
	2. une amie intelligente
	3. des amis intelligents
	4. das amies intelligentes
4. 有些形容词有专门的阴阳性形式，要单独记忆（beau，ce等）

##### 一般疑问句
用oui或non回答，把陈述句改为一般疑问句有三种方式：
1. 直接加问号
	1. Elle est ivre. > Elle est ivre? 
2. 主谓颠倒
	1. Elle est ivre. > Est-elle ivre? 
如果主语是名词，而且动词后面有宾语，变成疑问句时不能倒装，而要采取"名词+动词+和名词相应的主语代词"的形式

## 动词
### 第一组动词
#### 语法部分
除aller外，1453中所有以-er结尾的动词都是第一组动词，它们的变位是规则的，例如：
chanter的现在时变位

| chanter | 第一人称              | 第二人称             | 第三人称             |
| ------- | ----------------- | ---------------- | ---------------- |
| 单数      | je chant**e**     | tu chant**es**   | il chant**e**    |
| 复数      | nous chant**ons** | vous chant**ez** | ils chant**ent** |
注意：
1. **-ent** 作为第三人称复数的词尾不发音
2. 以 **-ger** 结尾的动词，第一人称复数的词尾前要加e，保持g读音不变：

| signer | 第一人称              | 第二人称        | 第三人称        |
| ------ | ----------------- | ----------- | ----------- |
| 单数     | je signe          | tu signes   | il signe    |
| 复数     | nous sign**e**ons | vous signez | ils signent |
3. 以 **-cer** 结尾的动词，第一人称复数的词尾c要软化，保持c读音不变：

| commencer | 第一人称            | 第二人称           | 第三人称           |
| --------- | --------------- | -------------- | -------------- |
| 单数        | je commence     | tu commences   | il commence    |
| 复数        | nous commençons | vous commencez | ils commencent |
4. aller的变位：

|     | 第一人称        | 第二人称       | 第三人称           |
| --- | ----------- | ---------- | -------------- |
| 单数  | je vais     | tu vas     | il/elle va     |
