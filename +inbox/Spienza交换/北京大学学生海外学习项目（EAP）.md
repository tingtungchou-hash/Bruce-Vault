# EAP申请指南

   EAP是学生海外学习项目Education Abroad Program的简称，旨在为北大在校生构建海外交流平台，提供短期海外学习的机会，让更多的学生在双重教育环境中形成国际化视野，将海外交流的成效引入北大校园，最终提高北京大学的国际化水平。
   北京大学EAP包括校际交流、寒暑期学校、奖学金及其它项目。

   **·校际交换**：学生可申请与北大有交流协议的国外高校进行时限为半年到一年的海外学习。作为北大海外学习项目的重要组成部分，校际交流项目对于帮助学生完成学业、拓展视野、培养国际意识并促进学术交流的国际化，实现北京大学创建世界一流大学的目标都具有重要意义。

   **·寒暑期学校**：寒暑期学校是国际上许多大学通行的做法，多为面向社会的开放式课堂，校际互认学分。寒暑期学校的上课时间通常比较紧张，一般持续4周左右，开放入学和多样化的学生群体是寒暑期课堂的重要特征。

   **·奖学金**：奖学金项目主要针对我校全日制正式在册毕业班的同学，申请到奖学金的同学毕业后可到国（境）外高校继续攻读学位。

   **·其它**：除校际交换、寒暑期学校及奖学金项目外，EAP还包括短期海外实习、中短期国际会议等海外项目。

  

**【一、申请流程】**

---

**1. 查询项目信息**

   登陆北京大学国际合作部网站http://www.oir.pku.edu.cn，链接进入"海外学习"栏目，根据项目类别选择希望申报的海外学习项目。

**2. 确认申报资格**

   查阅项目信息，确定您是否符合申请资格。凡符合项目要求的北京大学全日制正式在册学生，均可按规定程序和申请办法申请。

**3. 项目申请**

   确定申报项目后，按照项目要求，登录北大个人门户（海外学习项目）进行网上申请或递交书面申请材料。

**4. 材料审核及面试**

   进行网上申请或递交书面材料后，项目组将对申报人材料进行审核，选拔参与面试人员，并统一组织面试。

**5. 确认接收**

   面试合格者被提名到接收院校后，最终录取结果由对方确定。

**6. 办理手续**

   除个别项目统一组织外，录取学生需自行办理接收院校注册、校内出访及其它出国手续（如签证、机票、保险等）。

**7. 海外学习**

   完成出访手续后，项目成员须按项目规定期限前往接收院校参加交流项目，不得随意改变行程，未经批准不得擅自延长交流期限。

**8. 返校手续**

   项目成员完成海外学习后，按项目规定时间返回，完成返校手续并提交书面报告。

# **EAP常见问题**

**Q:  什么是学生海外学习项目（EAP）?**

**A:**  EAP是学生海外学习项目Education Abroad Program的简称，旨在为北大在校生构建海外交流平台，提供短期海外学习的机会，让更多的学生在双重教育环境中形成国际化视野，将海外交流的成效引入北大校园，最终提高北京大学的国际化水平。EAP主要包括校际交流、假期学校、海外实习、学位奖学金等。

**Q:  怎样获得EAP项目信息？**

**A:**  所有项目信息将公布在国际合作部EAP网站[http://www.oir.pku.edu.cn/Category_35/Index.aspx](http://www.oir.pku.edu.cn/Category_35/Index.aspx)。

**Q:  申请EAP项目需具备哪些条件？非校本部学生是否可以申请？**

**A:**  凡北京大学正式在册全日制学生、符合项目规定要求，均可申报学生海外学习项目。

**Q:  校际交换项目一般会在什么时候公布？是否可以选择交换时间？**

**A:**  校际交换项目通常会提前一学年公布。其中，美洲项目通常在每年12月份左右公布。欧洲、亚洲及大洋洲项目通常在每年3-4月份左右公布。申请成功后，通常除指定项目外，学生可自行选择下一学年度具体派出学期（美洲项目通常秋季学期派出，大洋洲项目一般春季学期派出）。

**Q:  参加校际交换的学生是否可以选择专业？**

**A:**  由于转换学分要求，参加校际交换的学生只可申请交换学校同专业或相似专业的课程。

**Q:  假期项目一般在什么时候公布？**

**A:**  假期项目一般分为寒假项目和暑假项目，寒假项目通常在每年10月份寒假前公布，暑期项目一般在每年12月份至次年5月份陆续公布。

**Q:  学位奖学金项目一般会在什么时候公布？**

**A:**  学位奖学金项目通常在每学年第一学期公布，录取结果一般会在寒假之后陆续公布。

**Q:  申请EAP项目的流程是什么？**

**A:**  通常，学生海外学习项目将公布在国际合作部网站。项目公布后，学生可通过在线申请系统进行网上申请。经EAP面试组进行材料审核或面试后公布最终结果。拿到录取通知后，除个别项目外，学生需自行办理护照、签证，购买机票、保险等事宜。

**Q:  申请EAP项目对外语有何要求？**

**A:**  申请学生海外学习项目的同学需具有较高的外语听说读写能力。根据具体项目要求，学生需提交大学英语四级、六级、专业英语四级、八级、雅思、托福等英语能力证明。其余非英语授课项目外语需符合对方学校项目规定。

**Q:  是否可以同时申请EAP的多个项目？参加过EAP项目的同学是否还可以申请？**

**A:**  如同类别项目派出时间重合，只可申请一个项目。一旦发现重复申请，将取消申请所有EAP项目的资格。曾参与过EAP项目、且按北大校方规定完成正常派出和复学手续的同学在符合项目要求的情况下均可再次申请。

**Q:  参加EAP项目一般需要支付何种费用？**

**A:**  校际交换：通常免除接收方学费。部分项目提供奖学金。  
假期项目：学生自行支付项目费用，部分项目有奖学金资助。  
学位奖学金项目：海外攻读学位的学费或生活费用一般由该奖学金支付。

**Q:  参加EAP项目是否可以转学分？**

**A:**  根据项目分类，通常，按规定完成EAP项目的学生（校际交换及暑期项目）可以转学分。参加一学期或一学年校际交换项目的同学，海外学习课程经院系评定可转为专业课学分。假期项目需在学校教务部转成公选或通选学分。本科生转换学分办法详见教务部网站。研究生一般不能转换学分。

**Q:  EAP项目简历筛选和面试的主要标准是什么？面试形式是什么？**

**A:**  EAP项目面试一般采用外语群面的形式进行。简历筛选和面试的主要考察学生与项目的契合度、学生在校期间成绩、老师推荐意见及个人综合表现。

**Q:  参加EAP项目的同学享受哪些待遇？责任和义务有哪些？**

**A:**  参加学生海外学习项目的同学将自动成为北京大学EAP项目校友。EAP将会定期发送项目信息、学校大型外事活动信息至个人邮箱。参加项目学生应履行EAP校友义务，为下届参加此项目的同学给予指导和帮助，并在项目结束之后提交项目总结、图片和视频资料。

**Q:  通过北大国合简历筛选和面试后，是否意味着已被该项目录取？**

**A:**  通过北大国合简历筛选和面试，将获得北大校方推荐资格，最终录取与否仍由接收校方决定。

**Q:  海外学习期间是否需要购买保险？**

**A:**  如海外高校未统一购买人身意外险及个人医疗保险，学生在海外学习期间必须购买两种保险。

**Q:  申请项目成功后以及项目期间是否可以退出项目？**

**A:**  如因特殊原因不能按期完成项目，学生需及时通知学生交换项目办公室。学生需自行负担所有因此产生的相关费用。

**Q:  申请EAP项目是否需要提交报名费？如中途退出，是否需要提交违约金？**

**A:**  EAP项目通过学校国际合作部公布和组织，无需提交报名费和注册费。项目学生确认参加后，如无特殊原因中途退出，无需交纳违约金，但将记录在学生海外学习项目档案中，可能影响以后参加国际合作部海外学习项目的申报资格。请学生在申报项目前仔细阅读项目要求。

**Q:  是否可以延长项目参与时间或提前结束参与项目？**

**A:**  如无特殊原因，不可任意延长参与项目时间或提前结束项目。如有特殊原因，需向EAP提交申请，待审批后方可执行

**Q:  关于学生海外学习项目如有疑问，通过何种途径可以咨询？**

**A:**  学生海外学习项目专设咨询邮箱面向全校师生开放，pkueap@pku.edu.cn。通常收到邮件后会在1-2天内给予答复。由于咨询人数众多，恕不接待来访来电。 

**Q:  入选EAP项目后，学生需要办理哪些离校手续？**

**A:**  参加假期项目等短期项目的同学在出发前需向国际合作部提交《北京大学学生出访申报表》和《校级海外学习项目责任书》。  
参加一学期及以上长期项目的同学仍需交纳北京大学学费，并在行前院系教务办公室办理交换学期的注册手续、停学手续  
项目结束后完成复学手续。同时向国际合作部提交《北京大学学生出访申报表》和《校级海外学习项目责任书》。

**Q:  国际合作部是否有针对参与EAP项目学生的奖学金？何时申请？申请资格是什么？**

**A:**  目前，国际合作部奖学金只面向入选EAP常规校际交换项目且未曾获得项目及其它任何形式奖学金资助的学生申请。奖学金设为三等，最高资助20,000元/项目。目前，该奖学金暂不面向短期项目（假期项目、短期访问考察项目等）学生申请。

一、申请资格：

二、申请方式：

在线申请：登录北大个人门户——海外学习项目

三、申请材料：

1、个人证件照片

2、中文推荐信

3、中文成绩单

4、外语能力证明（授课语种）

四、选拔过程

1、通过材料筛选，确定面试名单；

2、由国际合作部、教务部、研究生院及专业教师组成评审组面试，遴选确定推荐候选人；

3、候选人通过面试后，可获得我校推荐资格并按照接收院校要求准备申请材料，录取结果由接收院校最终审定；

4、拟于12 月中下旬组织面试。

五、截止日期：11月17日（星期二）15:00

六、项目资助

2020年，在北京大学教育基金会的大力支持下，学校设立相关资金，集合社会各界捐赠，更大程度为EAP项目学生提供资金支持。入选此次交换项目的同学可申请EAP资助。

七、注意事项：

1、本次公布项目涵盖2027-2028学年度全部校级交换项目（特殊项目除外）；

2、申请采用线上申报方式，不接收纸质材料；

3、申请人限申报一个项目，重复申请将取消申请资格；

4、申请人所选交流院校及交流时间需征得所在院系同意，应结合本专业培养方案与学业进度合理安排交流计划，以免影响正常毕业；

5、申请人需提前登录合作院校官网，仔细阅读申请要求。包括成绩、专业限制、交换时间是否与我校校历冲突、年级限制、外语等级和截止日期等，若因未达到录取要求而未能最终录取，学生自行负责；

6、申请要求以接收院校发布信息为准，附件内容如有更新，将以红色标注；

7、若交流院校无外语要求，需上传大学英语四六级、雅思、托福或GRE成绩。申请非英语授课项目的，需提交对应语种的语言能力证明。若确实无法提供外语能力证明，请务必在备注栏说明，以便评估是否符合项目要求。凡未上传任何外语能力证明，且未在备注中说明的，材料初审不予通过；

8、申请非英语授课项目时，申请人需在北大网申系统备注所选项目授课语种。面试采用授课语种进行。调剂阶段，获得调剂资格的申请人需选择授课语种与面试语种一致的项目进行调剂；

9、若申报时仍未取得达标的外语成绩，可先申报再考取。申请人需确保在外方截止日期前提供符合要求且仍在有效期内的正式成绩。由于申请人数较多，初审将根据申报材料择优面试；

10、硕士一年级申请者如尚未获得成绩单，需提交本科阶段成绩单；

11、推荐信应由我校所在专业专任教师（研究生需为本人导师）出具。推荐信包含推荐院校名称、推荐人职务及联系方式，并须由推荐人签字；

12、留学生不得申请本国交换项目；

13、交流学期为本人毕业学期的不可申报；

14、为确保学分转换并顺利完成北大学业，交换期间所选学科专业须与在校专业相符。专业不符将无法通过材料初审；

15、因交流名额有限，在同等条件下将优先考虑未曾入选过EAP交流项目的学生；

16、入选我校推荐资格的同学，一旦确认参加，如无特殊原因不可退出，否则将影响其它项目申请；

17、申请人需对申报内容的完整性、真实性和有效性负责。如有虚报瞒报的情况，一经发现将取消资格；

18、项目成员在出访前需按要求完成我校出访手续并审批通过。项目成员应按照项目规定期限往返，未经批准不得擅自改变行程，包括出访时间和交流期限等；

19、项目成员应遵守两校校规校纪及当地法律法规。期间如因成绩问题或其他原因不再适合参加项目，将取消资格。
