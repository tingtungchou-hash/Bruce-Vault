# Bruce's Obsidian Vault 使用指南

## 你是谁
你是 Bruce，北大历史学系学生，主攻罗马史/古典学。你同时学习拉丁语、法语、意大利语（即将学古希腊语）。这是你的 Obsidian 知识库。

## Vault 结构

### 文件夹组织
```
/                        # 根目录 — 零散笔记放这里
├── 工具书/               # 工具书 PDF（词典、语法指南等）
├── 已结课课程/            # 已结课课程笔记
│   └── 大二下/           # 大二下学期
├── 意大利语/             # 意大利语学习资料（PDF + 笔记）
├── 拉丁语/               # 拉丁语学习资料（PDF + 单词本）
├── 政治文化 - 文献/       # 罗马政治文化文献
│   ├── 政治文化 I/
│   ├── 政治文化 II/
│   └── 政治文化 III/
├── 教务文件/             # 教务文件（培养方案、选课手册等）
├── 法语/                 # 法语学习资料（PDF + 笔记）
└── 证书扫描件/           # 证书扫描件
```

### 文件命名规范
- **课程笔记**: `YYYY-课程名.md`（如 `2025-罗马帝国艺术.md`）
- **单词本**: `语言-单词本-主题.md`（如 `拉丁语单词本-De Bello Gallico.md`）
- **文献笔记**: `作者_年份_标题.md`
- **每日笔记**: `YYYY-MM-DD.md`（用 Obsidian Daily Notes 插件）

### YAML Frontmatter 规范
每篇笔记都应包含：
```yaml
---
title: ""
created: {{date}}
tags: []
status: seedling     # seedling | growing | evergreen
---
```

### 标签体系
- `#course/xxx` — 课程相关
- `#language/latin` — 拉丁语
- `#language/french` — 法语
- `#language/italian` — 意大利语
- `#language/greek` — 古希腊语
- `#vocabulary` — 词汇
- `#literature` — 文献笔记
- `#exam` — 考试相关
- `#daily` — 每日笔记
- `#reading` — 正在阅读的文献

## 常用工作流

### 上课记笔记
1. 从模板创建课程笔记
2. 记录核心概念、疑问、关键词
3. 课后整理，链接到相关已有笔记
4. 标记状态为 `growing` → `evergreen`

### 语言学习
- 每个单词创建一个笔记（或按主题/课本分组）
- 用 `[[wikilink]]` 连接同源词、同语族词
- 标注词源（拉丁语源、希腊语源等）
- 添加例句

### 文献阅读
- 在 `政治文化 - 文献/` 下对应子文件夹创建阅读笔记
- 链接到 PDF 的具体页面：`[[文献.pdf#page=42]]`
- 提炼核心论点、证据、个人评论

### 考试复习
- 创建 `考试-课程名-YYYY.md`
- 列出考点、重点、难点
- 链接回相关笔记形成复习网络

## Claude Code 交互约定

### 当你叫我时
- 我默认你对 vault 中的内容已经熟悉，我会帮你：
  - 整理/补充笔记
  - 解释复杂概念
  - 生成学习材料（闪卡、练习题）
  - 关联不同学科的知识
  - 检查语法/翻译（拉丁语、法语、意大利语）
  - 帮你准备考试

### 教学风格
- 用中文解释，但保留术语原文（如 *senatus consultum ultimum*）
- 使用 Obsidian wikilink 格式 `[[链接]]` 组织知识
- 复杂概念用表格、列表结构化呈现
- 提及来源时引用你的 PDF 文献
- **禁用 emoji** — 所有内容生成禁止使用 emoji，包括标题、列表、状态标记、提示语等任何位置

### 常用命令
- "帮我整理这节课的笔记" — 从对话/草稿生成结构化笔记
- "帮我做闪卡" — 从笔记提取 Q&A 对
- "解释这个词的词源" — 跨语言追根溯源
- "帮我准备考试" — 生成复习提纲
- "检查这段拉丁语翻译" — 语法和翻译校对
