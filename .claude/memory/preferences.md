# Bruce 的偏好

## 语言笔记编辑规则

1. **音符与文字内容保护**：更改语言笔记（法语、拉丁语、意大利语、古希腊语等）时，除非明确要求，绝对禁止去掉音符、改变文字内容。仅允许裁切、位移、拆分、合并等结构性操作。
   - 增减 wikilink 链接不受此限制。

2. **笔记中禁用 emoji**：禁止在写入或修改 .md 笔记时添加 emoji。对话中的回复不做此限制。

## 导航更新规则

1. **文件更新后检查上级导航**：在创建、修改或更新任何文件后，检查该文件所在目录是否存在导航页（如 `单词表 - XXX.md`、`主页.md` 等汇总/索引类文件），若有则更新导航链接，确保新文件被正确纳入。如果目录内文件构成序列（如课程、词汇的分课结构），还需检查同级导航（上一页/下一页/返回目录）是否需要同步调整。
