# Bruce 的偏好

## 语言笔记编辑规则

1. **音符与文字内容保护**：更改语言笔记（法语、拉丁语、意大利语、古希腊语等）时，除非明确要求，绝对禁止去掉音符、改变文字内容。仅允许裁切、位移、拆分、合并等结构性操作。
   - 增减 wikilink 链接不受此限制。

2. **笔记中禁用 emoji**：禁止在写入或修改 .md 笔记时添加 emoji。对话中的回复不做此限制。

## 文件操作后必做检查

> 每次 Write、Edit、Move（Bash mv）操作完成后，**立即逐项执行以下检查，不得跳过**。

1. **上级导航更新**：该文件所在目录是否存在导航页（如 `单词表 - XXX.md`、`主页.md`、课程总导航等汇总/索引类文件）？若有，立即更新其中的链接和表格，确保新文件被纳入。
2. **同级序列导航**：目录内文件是否构成编号序列（如 `01-xxx, 02-xxx, ...`）？若是，检查同级导航（上一页/下一页/返回目录）是否需要同步调整。
3. **Wikilink 括号配对**：在新创建或修改的文件中搜索 `\[[^\]]+\]`（单个方括号包裹，排除 markdown 外链 `[text](url)`）和 `\]{3,}`（连续三个以上右括号），如有异常立即修复。
