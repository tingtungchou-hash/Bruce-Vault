# 备份

手动备份 vault 到 GitHub。执行完整的 add -> commit -> push 流程。

## 用法

在对话中输入 `/备份`，我会自动执行。

## 操作

```bash
cd "D:\knowledgebase\Bruce's Vault"
git add .
git commit -m "backup $(date '+%Y-%m-%d %H:%M')"
git push
```

## 说明

- 提交所有文件变更（新增、修改、删除）
- 提交信息包含当前时间，方便回溯
- 推送到 GitHub 远程仓库
- Obsidian Git 插件已配置每 60 分钟自动提交+推送，此命令用于在需要时手动触发
