steps:
  - "**判定范围**：默认对用户选中的句子（`<editor_selection>`）作分析；用户指定了某句或 `@文件` 时以指定者为准。多句则逐句各建一棵语法树与一组细部用法。"

  - "**选定目标笔记与位置**：默认写入当前笔记的 `# Grammar` 一节；该节不存在则新建。写入前先读原文，**不触碰存量内容**，仅在末尾追加（或按用户指定替换某句的分析）。"

  - "**排版**：每句以 `## 1.` / `## 2.` / `## 3.` 编号（**一律用阿拉伯数字，不用汉字序号**），标题后附该句拉丁原文；其下固定两个子标题，顺序为 `### 语法树`、`### 细部用法`。引用的拉丁原句若含方括号标记，用反引号代码格式包住，避免被 Markdown 误读。"

  - "**画语法树（核心步骤）**：置于代码块内，用 `├─`、`└─`、`│` 绘制缩进树，自「主句」起逐层展开，每一层是一种句法成分。**树中只保留最核心的成分名与词形，一律不写形态标注** —— 性·数·格、时态·式·语态、人称·数等形态信息全部留到「细部用法」中讲，不进树。节点格式仅为 `成分名 词形`（如 `主语 Nēmō`、`谓语 est`、`施事 ab illō`）。理由：树行越短越好，**行过长会触发编辑器自动换行，折断树形结构**。展现的是**层级与修饰从属关系**，不是词序。省略、无音形等用 `⌀` 标出。成分标签用中文，且尽量简短。"

  - "**列细部用法**：形态信息集中在此处给出（因语法树中已不再标注）。按**词**（而非按话题）分点，每点以 `**词形**［形态］：` 起头。凡涉及时态、式、语态、句法功能、形式警示（与别的时态或式同形，如完成时虚拟式与将来完成时陈述式）、词序交错（hyperbaton）、修辞（litotes / chiasmus / asyndeton 等）者单列子项，先说「式」再说「时态」。拉丁原文用 *斜体*，**必须保留全部长音符与音符**（ā ē ī ō ū 等），不得去除。"

  - "**附译文**：以 `> 译文：` 引用块收尾。直译优先，必要时另补一句通顺译。"

  - "**输出质量检查**（返回用户前必须执行，沿用 CLAUDE.md 后验规则）：1) Wikilink 括号配对，无 `]]]`，无单括号形式的坏链；2) 长音符 / 音符完整性抽查；3) 代码围栏（```）成对闭合。发现即修正，再输出。"

  - "**汇报**：一句话说明分析了哪几句、写入哪个笔记的哪一节、树中共标注了哪些句法层级。"
