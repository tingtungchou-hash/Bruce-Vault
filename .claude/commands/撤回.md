# 撤回

将文件恢复到上一次 Git 提交时的状态。用于撤销误操作（如脚本写坏文件、误删内容等）。

## 用法

### 撤回单个文件

```
/撤回 法语/Note - 速成法语 - 孙凯.md
```

### 撤回所有文件

```
/撤回 全部
```

## 操作

```bash
cd "D:\knowledgebase\Bruce's Vault"

# 撤回单个文件
git checkout -- "文件名.md"

# 撤回所有文件到上次提交
git reset --hard HEAD
```

## 说明

- 只影响**未提交**的更改——已经 commit 的内容不会丢失
- `git reset --hard HEAD` 会丢弃上次提交之后的所有未提交更改，慎用
- 如果更改已经 commit 但还没 push，可以用 `/备份` 先推上去，不会丢失
