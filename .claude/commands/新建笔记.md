description: "从零创建带导航栏的课程 / 语言 / 文献笔记：判定类型与路径、组装导航栏、生成 frontmatter 与正文骨架，并把新笔记接入上级导航（保证最少链接可达）"
steps:
  - "**判定笔记类型**：课程笔记 / 语言笔记 / 语言练习 / 文献笔记。
     来源优先级：用户显式说明 > 当前会话的 linked_note 所属类型 > 用户消息中的 `@文件` > 目标所在文件夹。
     若无法判定，向用户确认，不要猜。"

  - "**判定目标路径**（映射 vault 结构）：
     - 课程笔记 → `Areas/学业/课程/<学期>/<课程名>/`
     - 语言笔记 / 语言练习 → `Areas/语言/<语种>/笔记/<教材或课程>/`
     - 文献笔记 → `Areas/学业/文献库/<主题>/<分类>/`
     若目标文件夹不存在，向用户确认后再建。"

  - "**定位上级导航**（槽位 1）：
     - 课程笔记：在同课程文件夹内找 `*导航*.md`（如 `基础古希腊语(1)导航.md`、`中国近代史-导航.md`）
     - 语言笔记 / 练习：找教材导航 MOC（如 `Mastronarde Greek - D. J. Mastronarde.md`）或所在课程导航
     - 文献笔记：找该主题/分类的 MOC 或书目页；若确实没有，则删除槽位 1（并在输出中提示用户该分类缺 MOC）"

  - "**定位前 / 后一篇**（槽位 3、4）：
     - 读取上级导航中的「课程列表 / 表格 / 阅读进度」顺序，找出当前笔记的位置。
     - 新笔记尚未入列时，默认接在**列表末尾**：前一篇 = 当前末篇，后一篇 = 无（→ 删除槽位 4）。
     - 语言笔记与语言练习各自成序列：笔记找笔记邻居，练习找练习邻居。
     - 文献笔记仅在所在子序列（如某专题的阅读顺序）明确时保留 3、4，否则删除。"

  - "**定位教材 / 练习 / 参考**（槽位 5、6、7）：
     - 教材：语言笔记取该教材 PDF 的 wikilink；课程笔记取课程大纲或指定教材。
     - 练习：课程笔记取同课练习稿，语言笔记取 `... Unit X 练习.md`。
     - 参考：用户指定，或与本文最相关的一篇既有笔记。
     - **任一槽位没有真实目标就删除该槽位**，绝不写空占位或裸标签。"

  - "**组装导航栏**：读取 `.claude/导航栏槽位字典.md`，按「类型裁剪规则表」保留 / 删除槽位，按固定顺序渲染为单行：
     `<槽位1> | <槽位2> | ...`
     标签变体：课程笔记的 3/4 用 `上一课`/`下一课`；语言练习的 6 用 `本课笔记`。"

  - "**生成 frontmatter**（一律**不写 `status`** —— seedling / evergreen 已废弃，此规则优先于 CLAUDE.md 旧规范）。
     通用规则：`created`、`tags` 必填；**无值字段整行省略**（如无教师就不写 `professor`），不写空占位。

     课程笔记：
     ---
     title: \"<主题> <日期> <课简称>\"   # 如 \"鸦片战争 26-9-10 中近史\"
     created: {{date}}
     course: \"<课程名>\"
     professor: \"<教师>\"        # 无则删
     semester: \"<学期>\"
     tags: [course]              # 语言类课程补 language/greek 等
     ---

     语言笔记 / 语言练习：
     ---
     title: \"笔记 - Unit X\"       # 练习则 \"练习 - Unit X\"
     created: {{date}}
     language: \"拉丁语\"           # 拉丁语 / 法语 / 意大利语 / 古希腊语
     tags: [language/greek]
     ---

     文献笔记：
     ---
     title: \"<Title>\"
     created: {{date}}
     author: \"<Author>\"
     year: <YYYY>
     tags: [literature, reading, <主题tag>]
     ---
     （标签一律英文，遵循 CLAUDE.md 标签体系）"

  - "**生成正文骨架**（创建时留空，取自对应分类模板）：
     - 课程笔记 → `System/Templates/课程笔记模板.md`
     - 语言笔记 → `System/Templates/语言笔记模板.md`
     - 语言练习 → `System/Templates/语言练习模板.md`
     - 文献笔记 → `System/Templates/文献笔记模板.md`
     导航栏与正文之间以 `---` 分隔。"

  - "**文件命名**（沿用各类型既有模式）：
     - 课程笔记：`<主题> <日期> <课简称>(<序号>).md` = `title` 加 `(<序号>)` 后缀，
       如 `鸦片战争 26-9-10 中近史(2).md`、`导言 26-9-8 中近史(1).md`。
       `<主题>` 取该次课的主题（如 鸦片战争 / 导言 / 第一课），`<课简称>` 取课程简称（如 中近史 / 古希腊语 / 拉美史 / 世文地）。
       先 `ls` 目标文件夹确认该课程已有命名模式，再照此生成。
     - 语言笔记 / 练习：`<教材名> Greek - Unit X 笔记.md` / `... Unit X 练习.md`
     - 文献笔记：`Note - <Author> (<Year>) <Title>.md`"

  - "**写文件 + 接入上级导航**：把新笔记**追加**到上级导航的课程列表 / 阅读进度表（保证最少链接可达，避免孤儿）。仅新增该笔记对应的一行，**不触碰存量行**。"

  - "**输出质量检查**（沿用 CLAUDE.md 后验规则，返回用户前必须执行）：
     1. Wikilink 括号配对：逐行确认 `[[` 与 `]]` 数量相等；无单括号形式（排除合法外链 `[text](url)`）；无三个及以上连续的右括号。
     2. 音符 / 音标完整性：涉及法语、拉丁语、意大利语、古希腊语时，抽查长音符号与重音（ά ῆ ῶ é è ê ç à â î ô ù œ æ 等）保留。
     3. 若新建的是导航 / MOC，用 `find` 逐条校验页面内每个 `[[target]]` 指向的 `.md` 存在，报告断链。
     发现即修正，再输出。"

  - "**提示用户**：完成后一句话汇报 —— 类型、路径、导航栏实际内容、以及被裁剪的槽位（如「无练习、无下一篇，已删除槽位」）。"
